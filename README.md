# 电子鹦鹉

站点标题：**电子鹦鹉**。里面住着一只**黄桃牡丹鹦鹉（公）**。它会饿、会渴、会脏、会生病、会记仇，然后等着你回来。

- 关掉页面，时间照样在走。你走了一整天回来，它是有账的。
- 界面上没有数字状态条。它好不好，只能看它的姿态、羽毛、叫声，和它自己写的那本记事本。
- 攒够怨气（或者被饿到一定程度），它会**自己把笼门打开飞出去**。笼子空着，门开一条缝，得道歉哄回来。

## 先看一眼它长什么样

不用装任何东西，直接双击打开：

```
bird-preview.html
```

八种姿态：`normal`（站着）/ `happy`（磨嘴点头）/ `angry`（竖羽炸毛）/ `hungry`（张嘴要食）/ `asleep`（单脚埋脑袋）/ `sick`（病了、发灰、头耷拉）/ `wet`（刚洗完澡）/ `away`（笼子空了）。
想重新生成：`npm run bird`。

## 跑起来

**最快的方式：双击 `启动.bat`。** 依赖已经装好了，它会直接起服务并打开浏览器。

或者手动：

```bash
npm install
npm run dev
```

打开 http://localhost:5173 。第一次打开是起名页，名字已经填好「糖糖」，点一下「就叫这个」就开始了。

想直接看时间流逝的效果（不用真的等一天）：

```
http://localhost:5173/?debug
```

右下角会出现一台「时间机器」，+1 小时 / +8 小时 / +1 天 / +3 天 随便跳。跳 3 天就能看到它飞出去，跳 2 天能看到它生病。

跑不动的话先跑这条，它会把界面在无浏览器环境下渲染一遍：

```bash
npm run check
```

## 怎么玩

底部是**常用**一排 + **8 个分类的互动表**，一共 **114 条互动**，每条都有自己的一句话反应。

**常用**（常在）：洗澡、打扫、盖布睡觉、放它出来、看它表演、凶它、道歉、问它记不记得。

**互动表**按页签切换：

| 页签 | 条数 | 例子 |
| --- | --- | --- |
| 吃 | 24 | 瓜子、谷穗、西兰花、西瓜、熟鸡蛋、面包虫、蜂蜜棒、墨鱼骨…… |
| 喝 | 8 | 换清水、温水、冰水、蜂蜜水、苹果汁、滴水壶…… |
| 玩 | 22 | 铃铛球、秋千、纸箱、纸巾卷、躲猫猫、追手指、旧键盘、快递箱…… |
| 摸 | 10 | 摸后颈、挠耳后、碰喙、托脚、摸背（它会躲）、吹气（会记仇）…… |
| 训 | 14 | 点头、转圈、上手、倒挂、开笼门、投篮、装死、说你好、翻跟头…… |
| 摆件 | 12 | 加栖木、挂镜子、铃铛、澡盆、磨喙石、梯子、吊桥、绿植…… |
| 声音 | 10 | 叫它名字、吹口哨、放音乐、学它叫、敲桌子、吸尘器（它会炸毛）…… |
| 日常 | 14 | 开窗、晒太阳、放它上肩、称体重、剪指甲（记仇）、陪它打盹…… |

**同一条互动，它会看情况给不同反应**：饿着吃不下、气头上不让摸、生病了谁都不理、睡着了碰一下就醒、水盆满了不想喝——所以同样的按钮在不同状态下不会重复。

## 等级与解锁（扩展包）

它有等级，Lv.1 到 Lv.8，顶上一根经验条。经验来自照顾和陪它：摸一下 +4、喂饭 +4、玩 +7、洗澡 +6、教口哨 +12、**完成当天心愿 +30**、**每天第一次来 +15**；凶它 −10。

新玩法按等级一次放出来，一开始锁着的按钮会写「· Lv.2」：

| 等级 | 解锁 |
| --- | --- |
| Lv.1 | 喂食、换水、摸、逗、凶、道歉 |
| Lv.2 | 洗澡、打扫笼子 |
| Lv.3 | **每日心愿** |
| Lv.4 | 玩具 |
| Lv.5 | 放它出来 |
| Lv.6 | **训练** |
| Lv.7 | **口哨教学** |
| Lv.8 | **表演** |

从 Lv.1 练到 Lv.8 一共 392 经验。开着 `?debug` 的话，右下角的**「+50 经验」**能直接把等级顶上去预览后面的内容。

### 每日心愿

每天第一次打开会抽一个愿望，右侧卡片上写着进度点：

- 它今天想吃某样东西（瓜子 / 苹果 / 玉米 / 面包虫）
- 它今天想让你陪它玩 3 次
- 它今天想被摸 4 次
- 它今天嫌笼子脏（打扫一次）
- 它今天想洗澡

做到 → +30 经验、心情 +10、亲密度 +4，它会说一句「今天这件事，你做到了」。没做到就过期，第二天换一个。

### 训练与技能

五个动作：**点头 / 转圈 / 上手 / 鞠躬 / 亲亲**。每次训练随机挑一个还没学会的，成功率 = `0.34 + 亲密度/260 + 心情/500 − 怨气/300`——所以关系越好越容易教。学过的东西会列在右侧「会做的事」里，Lv.8 之后可以「看它表演」，它会挑一个做给你看。

### 口哨教学

点「教口哨」弹出一排五个音（哆唻咪唆啦），按你自己的顺序点，然后「教它这段」。它会用鸟的嗓子把这段吹回来（第二声会高半度），并且记住这段——之后闲聊时你会看到「（它吹了一遍你教的那段，中间错了两个音，然后又从头吹。）」

### 它是怎么变的

- **五个需求**：饱食、口渴、清洁、体力、心情。任何一个见底，头顶就会出现提示（"饿了""渴了""脏了"）。
- **生病**：长期饿/渴/脏 → 健康掉到 34 以下 → 生病。病了羽毛松着、缩成一团、拒绝玩和洗澡、发灰。得喂饱、弄干净、让它休息，健康回到 62 才自愈。
- **好感等级**：还不熟 → 眼熟 → 认得你 → 黏着你 → 只认你（看标题栏）。
- **随机事件**：你不在的时候它会自己过：撕纸箱、跟影子吵架、晒太阳、打翻水盆……回来能在记事本里读到。
- **记仇**：凶它、饿着它、长时间不来看它，都会写进记事本。攒到 88 它就飞走。

### 为什么没有"打字跟它说话"

做过一版：用关键词表判断好话坏话。问题是它只会"记住原话"却听不懂，骂它也没反应——那不是 AI，是字符串匹配装出来的。既然要装就得接真模型，所以这版**把说话功能删了**，换成上面这些有实感的行为反馈。

## 互动时它真的会动

表情是"状态"，动作才是"它做了什么"。114 条互动现在每条都挂了一个动作（共 12 种），点下去它真的会做：

| 动作 | 用在哪些互动 |
| --- | --- |
| 低头啄（32） | 吃的东西、撕纸、抠键帽、擦笼子 |
| 跳一下（20） | 玩具、摆件、上肩、上手 |
| 蹭你的手（10） | 摸后颈、挠耳后、挠下巴…… |
| 抬头叫（9） | 所有"声音"类、挂镜子、学它叫 |
| 抖羽毛（8） | 洗澡、喷水雾、晒太阳后的甩水 |
| 仰头咽（6） | 换水、蜂蜜水、冰水 |
| 缩成一团（6） | 摸背、吹气、剪指甲、吸尘器、装死 |
| 探头钻进去（5） | 纸箱、快递箱、纸袋、躲猫猫、倒挂 |
| 扑翅（5） | 追手指、撕纸游戏、带它出门、绕圈飞 |
| 梳羽毛（5） | 数羽毛、安静十分钟、陪它打盹 |
| 张开翅膀（4） | 晒太阳、开窗、加澡盆 |
| 转个身（4） | 秋千、跳板、转圈 |

做法是 **CSS 驱动已有部件**（头 / 身 / 翅三个分组），不新增任何图形——所以 7 个品种、8 种姿态共用同一套动作，也不会跟呼吸、眨眼、点头求偶舞打架（动作播完自动回到待机）。
想加新动作：在 `src/pet/motion.ts` 里写一个 `@keyframes` + 一条映射就行。

## 一笼子鹦鹉

一开始只有糖糖（黄桃牡丹）。等级够了可以在顶上的「＋ 领养」里带新鸟回家，最多 5 只。

**每只鸟是独立的**：各自的饱食/口渴/清洁/心情/等级/技能/记事本/心愿，你切走它们也在过日子。顶上那一排是切换条，点名字就换过去。

**它们会吃醋**：你摸一只，其他几只怨气各 +2。所以别当着别人的面只撸一只。

**有伴就不无聊**：笼里超过一只时，「无聊」这个需求不再出现。

| 品种 | 外观 | 性格修正 | 领养需要 |
| --- | --- | --- | --- |
| 黄桃牡丹 | 黄身桃脸、短尾、粉脚 | 怨气 ×1.25（记仇最快） | 一开始就有 |
| 绿桃牡丹 | 原色绿身桃脸 | 怨气 ×1.15 | Lv.4 |
| 蓝虎皮 | 蓝身白脸、**短喙 + 长尾（×1.5）** | 怨气 ×0.85、**训练 +0.16**（最好教） | Lv.5 |
| 绿虎皮 | 同款换色 | 怨气 ×0.9、训练 +0.14 | Lv.6 |
| 玄凤 | 灰身黄脸、**冠羽**、橙腮点、长尾 ×1.7 | 训练 +0.08、脏得慢 | Lv.7 |
| 和尚 | 绿身灰胸、**大浅喙**、尾 ×1.3 | **脏得快 ×1.35**（最能拆） | Lv.8 |
| 太阳锥尾 | 橙黄身、长尾 ×1.9 | 亲密度涨得快 ×1.3、心情波动大、嗓门最大 | Lv.9 |

七种鸟用的是**同一套画法 + 不同参数**（颜色、冠羽高度、尾巴倍数、喙大小、虎皮横纹），所以换品种不会跳出同一个造型语言。想加新品种，只要在 `species.ts` 里写一段配置。

## 时间规则

- 饱食 `-1.8/小时`，口渴 `-2.4/小时`，清洁 `-1.3/小时`（出笼子时 4），体力醒着 `-1.2/小时`、睡着 `+8/小时`。
- 离开超过 5 小时开始攒怨气，超过 6 小时回来会看到一张纸条。
- 怨气 ≥ 88，或者「饿/渴到 0 且怨气 ≥ 70」→ 开笼门飞走。
- 飞走后道歉能把怨气降到 45 以下，它才肯回来（「我回来了。不是因为原谅你，是因为饿了。」）。
- 凶一次 +20 怨气，好话靠摸头和玩耍慢慢攒。所以连着凶 5 次，它当场就走。

所有状态存在 `localStorage` 的 `grouchy-pet.v1` 里，换浏览器就没了，清缓存也会没了。**老存档会自动升级**（缺的口渴/清洁/健康补默认值）。

## 它的样子是怎么画的

外观全部在 `src/pet/bird.ts`：

- `PALETTE` 决定羽色。默认是**黄化**（全身黄 + 桃脸 + 粉脚 + 白眼圈）。
- `BODY` / `HEAD` 是两条贝塞尔路径——身体是横长的蛋形（宽 148 × 高 126），头有平额头和下颌转折，都不是正圆。
- `beak()` 画喙：上喙收成一个尖点，下喙退在后面，生气时才微张（张开会垫一块暗色口腔，不会漏背景）。
- `birdCss()` 是它身上的动画：呼吸、转头、眨眼、甩尾、点头求偶舞；病了发灰耷头，湿了抖水。

  preview.ts              生成 bird-preview.html（npm run bird）
  ssr-check.cjs           不用浏览器把界面渲染成 HTML，检查能不能跑（npm run check）

## 装依赖踩过的坑

这台机器上有 TLS 中间人代理，`npm install` 可能报 `UNABLE_TO_VERIFY_LEAF_SIGNATURE`：

```bash
npm config set strict-ssl false
```

pnpm 11 默认禁止依赖执行安装脚本，`esbuild` / `rollup` 的二进制装不下来，`vite` 会报 `Cannot find package 'esbuild'`。要么用 npm 装，要么先跑 `pnpm approve-builds`。

Windows 的 `.bat` 必须是 **CRLF 换行**，写成 LF 会让 cmd 把每行开头几个字符吃掉（表现是一堆"不是内部或外部命令"）。这个仓库里的 `启动.bat` 已经是 CRLF + 纯 ASCII。

## 还能往上加

- 它主动发系统通知（`Notification` API），隔天没来催你一次。
- 记事本导出成图片发出去。
- 笼内小地图：它会真的在笼子里走动、爬笼、倒挂。
- 玩具/食物做成背包 + 商店，用"亲密度"解锁新品。
